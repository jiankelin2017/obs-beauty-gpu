# OBS 美颜 GPU 版

> **一句话**：把一个原本全在 CPU 上的五段人脸美颜，整体搬到 GPU 的 OBS 滤镜。
> 生产默认路径 **4K 往返 ≈2.3–2.8 ms**、**720p ≈0.8–1.5 ms**（移植前 4K 是 81 ms / 约 7 fps）。
>
> - **装机 + 已验收：2.14.0**（`MD5 2BCE8C967956FAC72F337D482CF75CC6`，585,728 B）—— 装机 / `02_构建` / `07_安装包` 三处逐字节一致（`Setup.exe` `76A4E6EF…`）；`check_release.py` 九项全 PASS
> - **2.14.0 是默认行为变化（本分支第一处）**：五官段 `BEAUTY_GPU_REGION` 由「默认关、认 `=1`」翻成
>   「**默认开、只认 `=0`**」，不设环境变量的用户从此默认走 GPU 五官。
>   依据 T10-b 的 17 格等价矩阵（17/17 PASS，最坏 **1 灰阶 / 31 像素**，`PROGRESS §9.37` + `§9.40` 的遮挡格 + `§9.41` 的超小脸格）；
>   多脸（`faceCount≠1`）仍自动回退 CPU，**画面与之前逐字节相同**。
>   开关两侧实机日志都验过（`§9.39`）；回退只需 `BEAUTY_GPU_REGION=0`，不必换 dll。
> - **2.13.1 修掉 N1（输入旋转静默失效）**：旋转提到 `letterboxRgb` 之前做进重采样，**全帧回退路径也会转**了，
>   不再依赖 S4b 缩略图路径。`rot=0` 仍走原函数，四个黄金基准 `maxdiff=0`。
>   实机验收（正面机位 + 真人，`PROGRESS §9.36`）：`有脸` **100% / 1% / 2% / 0%**（`ir=0/90/180/270`，两轮独立采样同结论）——
>   2.13.0 及以前四臂会给出同一个数（旋转根本不进全帧路径）。
> - **2.11.0 新增**：方案C「运动判定搬 GPU、检测输入只在提交帧回读」，**默认关**（`BEAUTY_MOTION_GPU=1` 开启）。
>   配对实测 720p 往返 **0.73→0.47（−36%）**、4K **2.22→1.85（−17%）**，六配置 `maxdiff=0`（`PROGRESS §9.29`）；
>   脸持续在场、每 60 帧消失 1 帧的素材上往返 **1.07→0.43（−60%）**、`有脸 100% vs 98%`（`§9.31`）
> - **2.11.1 只加诊断**：窗口行多了 `判动=hit/calls 提交=N`，另加 `BEAUTY_MOT_DUMP`（存 64×64 小图）——
>   起因是 2.11.0 用「闪脸」素材压边界时白跑了一轮：那批素材**压不到方案C**（`§9.31.1`）
> - **2.12.0 新增**：S7 判据的块聚合 `max` → `RMS`（`BEAUTY_DET_ADAPT_AGG=rms`，**默认仍是 max**）。
>   真实说话素材上判动 **42.7%→7.1%**、`nopix` 33.6%→**76.5%**、同会话三臂往返
>   关臂 1.46–1.69 / `max` 1.57–1.65 / **`rms` 0.72–0.86（−50.2%）**；
>   代价是掩码更新频率 68.5%→23.5%，掩码边界偏移超羽化宽度的帧 0.5%→**7.9%**（`§9.33`）
> - **2.13.0 只加诊断 + 结账**：新 `BEAUTY_DET_OFFSET=dx,dy`（把掩码平移，量「偏 d 像素值多少灰阶」，默认 0 逐字节不变）。
>   结论：代价真实但**只在边界那条 ≈21 px 的带子里** —— 典型参数下平均每帧 **2.4% 的脸部面积差 ≥4 灰阶**、
>   单像素最大 13 灰阶（「磨皮开 vs 关」自身最大 14）；纯磨皮档只有 0.05% / 7 灰阶。
>   顺带更正：羽化是 **0.08 × 脸宽**（不是 0.12），所以「超羽化」是 0.5%/7.9% 而不是 0.0%/2.9%（`§9.34`）
> - **人眼 A/B 已定案（`§9.35`）**：闪烁 JND 标尺的门限落在 **+6 灰阶档**（`+6` 看得见、阴性对照看不见），
>   而 `rms` 的实测带幅度是 **7.04 灰阶（p50）、86.6% 的帧跨过门限**；对照组（`max` 录两次）只有 5.82 / 31.7%。
>   方法先自证有效：同臂两次逐像素差 **0**、正对照 **24.55 灰阶**。→ **判决：`rms` 不翻默认，只作 opt-in**
> - **新增离线闸门** `05_验证/check_release.py`：查「dll 自报版本 == 源码宏」「装机/安装包 == 构建产物」「四份着色器逐字节相同」「开关表 ↔ 源码 `getenv()` 双向覆盖」（`§9.30`）
> - 引擎：`gpu/2.0.0`（GPU 路径）｜ `core/1.6.0`（CPU 兜底 + 离线 golden 基准）
> - 本文按 **2026-11-04 的源码**逐条核对；每个数字都指明出处（`PROGRESS §x`），不写推算值。

## 1. 它是什么

一个 OBS 视频滤镜（`obs_beauty_filter`），挂在任意源上，输入源纹理、输出**同尺寸**纹理：

```
源纹理 ──► 磨皮 ──► 色调(清晰/美白/红润) ──► 五官(立体/亮眼/黑眼圈/法令纹/祛斑)
        ──► 细节(锐化/全局锐化) ──► 美形(瘦脸/大眼/下巴) ──► 输出
                    ▲
        人脸检测（YuNet onnx + YCbCr 肤色椭圆）──> 掩码 / 保护椭圆 / 五官几何
```

设计边界（有意为之，不是缺陷）：

- **不改输出几何**：滤镜输出恒为源尺寸、朝向不变；竖屏/旋转由 OBS 场景项负责（`§9.21`）。
- **不碰父源**：无 `obs_source_set_width/height`、无增删滤镜，滤镜链只读源纹理。
- **默认参数不为零**：磨皮出厂 **20**（其余 13 项为 0），所以「装上就有轻微磨皮」是设计。

### 2.4 工程与部署

- **装机脚本** `03_装机/7_install_gpu.ps1`：备份 → 装 dll + `data/shaders/*.hlsl` → 逐文件 MD5 校验 → 不一致即 `throw`；**拒绝在 OBS 运行时装机**。
- **shader 单一来源**：只有 `01_源码/shaders` 是手写源，其余（打包产物、装机运行时、开发 junction）全部由脚本生成（P2-3）。
- **安装包** `07_安装包/build_setup.ps1`：一条命令从 `02_构建` + `01_源码/shaders` 重打 `Setup.exe`，拷贝前先清空目标目录（防幽灵文件）。
- **一键回退**：每个新特性都有 `BEAUTY_*` 开关（见 `04_文档/开关总表.md`），默认值只认「`0` 关 / `1` 开」以防拼错。
- **采集前置 GPU 闸** `05_验证/gpu_guard.py`：显存 >3500 MiB 或重度占用时拒绝起 OBS，避免测出虚高帧时再误判成源码问题（§9.14）。

|---|---|---|
| N17 | `--collection X` 匹配的是集合 JSON 里的 `name` 字段，**不是文件名**；打偏是**静默**的 | 唯一判据：插件日志 `target=` 尺寸 == 素材尺寸（§9.23.3） |
| N18 | 面板单位是 **0..100**，不是 0..1 | `thin_face: 0.6` 等于拖到 0.6%（§9.19 整轮对拍因此跑在 1% 强度） |
| N19 | 参数要在**起 OBS 之前**写进集合 | 自检取「第一个满足条件的帧」，等 WebSocket 连上再下发已经晚了 |
| N20 | OBS **退出时会改写集合**（`pos_rel`/`pos` 被重算） | 两版对比前先恢复同一份集合快照，否则同图也能差 99.994%（§9.28.2） |
| N21 | 收益只认**同会话配对 A/B** | 搬运项跨会话不可比；4K 引擎容差另定 25%（§9.1.2） |
| N22 | 长跑日志会被轮转（OBS 只留最近 10 份） | 跑完立刻拷到 `05_验证/out/logs/` |
| N23 | 合成人像常因**色度过低落在肤色椭圆外** → `faces=0`、掩码 0% | 用 `make_front_assets.py` 的色度校正，别看 cv2 的检测结果（§素材） |

## 5. 验证怎么做

三条线，各管一段，缺一条就会得出错误结论：

| 线 | 命令 | 管什么 |
|---|---|---|
| 离线 | `05_验证/verify_{tone,smooth,region,detail,warp,mask}_compiles.py` | 着色器编译 + 入口签名 |
| 离线（引擎） | `06_离线验证/offline_regress.py check` | CPU 引擎 golden 四例（**动引擎接口/S4/S7 必跑**） |
| 装机采集 | `05_验证/verify_s1_correct.py capture/compare`、`verify_region_samemask.py`、`verify_spot_pixels.py` | 六配置逐像素、五官同掩码、祛斑像素量 |
| 性能 | `s0_lock.py` → `gate.py --skip-transfer --cmp`；收益用 `ab_pair.py` | 基线复绑 / 门禁 / 配对收益 |
| 稳定性 | `soak_s2.py soak --minutes 30` | 长跑、切换、热重载 |

判据口径（2026-11 定稿）：**搬运项跨会话不可比**（只由配对 A/B 判），跨会话只判引擎项 + 健康项
（`gskip/tskip` 取最坏窗口）。完整工具说明与 18 条坑：[`05_验证/README.md`](05_验证/README.md)。
