## 1. 它是什么

一个 OBS 视频滤镜（`obs_beauty_filter`），挂在任意源上，输入源纹理、输出**同尺寸**纹理：

```
源纹理 ──► 磨皮 ──► 色调(清晰/美白/红润) ──► 五官(立体/亮眼/黑眼圈/法令纹/祛斑)
        ──► 细节(锐化/全局锐化) ──► 美形(瘦脸/大眼/下巴) ──► 输出
                    ▲
        人脸检测（YuNet onnx + YCbCr 肤色椭圆）──> 掩码 / 保护椭圆 / 五官几何
```

设计边界（有意为之，不是缺陷）：

- **不改输出几何**：滤镜输出恒为源尺寸、朝向不变；竖屏/旋转由 OBS 场景项负责（`§9.21`）。
- **不碰父源**：无 `obs_source_set_width/height`、无增删滤镜，滤镜链只读源纹理。
- **默认参数不为零**：磨皮出厂 **20**（其余 13 项为 0），所以「装上就有轻微磨皮」是设计。

| 4K 20 min ×2（S4b1 最终版） | `tskip>0` **0/201 窗**，30.1 fps，`gate.py` PASS | §9.5.4 |
| 切换/热重载/冷启动 | 画布 720p↔1080p↔4K 来回 9 次不崩、热重载 3 轮、冷启动 7 次 | §9.3.1 |

### 2.4 工程与部署

- **装机脚本** `03_装机/7_install_gpu.ps1`：备份 → 装 dll + `data/shaders/*.hlsl` → 逐文件 MD5 校验 → 不一致即 `throw`；**拒绝在 OBS 运行时装机**。
- **shader 单一来源**：只有 `01_源码/shaders` 是手写源，其余（打包产物、装机运行时、开发 junction）全部由脚本生成（P2-3）。
- **安装包** `07_安装包/build_setup.ps1`：一条命令从 `02_构建` + `01_源码/shaders` 重打 `Setup.exe`，拷贝前先清空目标目录（防幽灵文件）。
- **一键回退**：每个新特性都有 `BEAUTY_*` 开关（见 `04_文档/开关总表.md`），默认值只认「`0` 关 / `1` 开」以防拼错。
- **采集前置 GPU 闸** `05_验证/gpu_guard.py`：显存 >3500 MiB 或重度占用时拒绝起 OBS，避免测出虚高帧时再误判成源码问题（§9.14）。
