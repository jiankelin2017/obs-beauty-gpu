## 默认值约定（很重要）

- **默认开**：不设 = 开，**只认 `=0` 关闭**（拼错环境变量会落在"开"这一侧，即已验证的安全侧）。
- **默认关**：不设 = 关，**只认 `=1` 开启**（拼错落在"关"这一侧，回到旧行为）。
- 数值型：不设 = 自动，设了按值生效。

## 一、引擎选择

| 开关 | 默认 | 作用 | 回退 / 说明 |
|---|---|---|---|
| `BEAUTY_ENGINE_IMPL` | 不设（默认实现） | 选引擎实现：`gpu` = GPU 引擎；`legacy` = 旧适配器（仅 `BEAUTY_WITH_LEGACY_ENGINE` 编译时） | 取消该变量即回默认 |
| `BEAUTY_GPU` | 不设 / `0` | 便捷别名：`=1` 等价 `BEAUTY_ENGINE_IMPL=gpu`（仅在后者未设时生效） | 取消 / `=0` |

## 二、生产链（默认开，改默认值就是这里）

| 开关 | 默认 | 作用 | 回退 / 说明 |
|---|---|---|---|
| `BEAUTY_GPU_SMOOTH_PROD` | **开** | Phase 3.5 GPU 磨皮生产路径（画面由 GPU 磨皮产出） | `=0` 退回 CPU 磨皮 |
| `BEAUTY_GPU_MASK` | **开** | GPU 掩码进生产链（替代 CPU 全帧掩码 + 上传） | `=0` 退回 CPU 掩码 |
| `BEAUTY_CHAIN_PROD` | **开** | 段区间钩子（磨皮→色调→五官→细节→美形留显存，5a） | `=0` 退回单段钩子 |
| `BEAUTY_CHAIN_OUT` | **开** | 链尾不回读（5b-1，直绘链纹理） | `=0` 退回回读+上传 |
| `BEAUTY_GPU_FRAME_RING` | **开** | 显存帧环（跳过对齐换帧的整帧上传，S2） | `=0` 关闭帧环 |
| `BEAUTY_DETECT_SMALL` | **开** | 检测输入走 GPU 预缩放 640×640 缩略图（S4b，需 `gpu_mask_chain` + 帧环） | `=0` 退回全帧回读（`tsm=0`） |
| `BEAUTY_ALLZERO_SKIP` | **开** | 全 0 参数直通短路（S1，跳过 GPU↔CPU 往返） | `=0` 关闭直通 |
| `BEAUTY_NOFACE_SKIP` | **开** | 无脸帧跳过整段处理（避免无掩码时全帧兜底磨皮） | `=0` 回到旧行为（全帧兜底） |
| `BEAUTY_ASYNC_DETECT` | **开** | 引擎异步人脸检测（离线对拍时须 `=0` 保证确定性） | `=0` 同步检测 |
| `BEAUTY_MASK_GEOM_ONLY` | 跟随内核（GPU 掩码链时为开） | 引擎只算几何、不画全帧 CPU 掩码（S4a） | `=0` 强制关闭 |

## 三、opt-in（默认关，需显式开启）

| 开关 | 默认 | 作用 | 回退 / 说明 |
|---|---|---|---|
| `BEAUTY_ASYNC_STAGE` | **关** | S3 暂存面双缓冲回读（输出整体晚一帧，≈33 ms，换掉 map 排队等待）。**与 S4b 缩略图路径互斥**：开启后 `tsm=0`，下载退回全帧 memcpy | 取消 / `=0`；须帧环可用 |
| `BEAUTY_GPU_REGION` | **关** | GPU 五官进生产链。2.8.1 起 4K 往返 **2.10 ms**（修复前 54–58 ms / 17.7–18.4 fps，根因是 geomOnly 帧拿不到 CPU 掩码导致五官链整段放弃，见 `PROGRESS §9.17`）。**仍 opt-in 的理由是「缺可靠判据」**：截图对拍在 geomOnly 路径不成立（四路子项差异完全相同，§9.19），而同帧自检 maxdiff=0 只有 1 个样本 | `=0` 退回 CPU 五官 |

## 四、诊断 / 对拍（默认关，只跑一次、不改画面）

| 开关 | 默认 | 作用 | 回退 / 说明 |
|---|---|---|---|
| `BEAUTY_GPU_TONE` | 关 | GPU 色调对拍（跑着色器 + 与 CPU 比，不改画面） | `=1` 开；失败什么都不做 |
| `BEAUTY_GPU_SMOOTH` | 关 | GPU 磨皮对拍自检（`beauty_gpu_smooth_selfcheck`） | `=1` 开 |
| `BEAUTY_GPU_DETAIL` | 关 | GPU 细节对拍（T1） | `=1` 开 |
| `BEAUTY_GPU_WARP` | 关 | GPU 美形对拍（5c） | `=1` 开 |
| `BEAUTY_GPU_MASK_CMP` | 关 | GPU 掩码对拍（M1，只比掩码） | `=1` 开 |
| `BEAUTY_REGION_CMP` | 关 | 五官整段对拍（4d）：同一帧、同一份掩码上跑 GPU 链与 CPU 基准 | `=1` 开。2.8.3 起 geomOnly 帧会自动把生产掩码读回当 CPU 基准的掩码（原来 `job.mask` 为空就跳过，几乎不触发） |
| `BEAUTY_REGION_CMP_N` | 1 | 对拍取样个数（1..20） | 配合 `BEAUTY_REGION_CMP`；一次对拍 = 3 次全帧回读，4K 会掉一帧 |

| 开关 | 默认 | 作用 | 回退 / 说明 |
|---|---|---|---|
| `BEAUTY_SHADER_DIR` | 不设（走装机 `data\shaders`） | 开发用着色器目录覆盖（免重装） | 取消即回正式路径 |
| `BEAUTY_MASK_EVERY` | 自动 | 异步检测提交周期：数值越大越省 CPU、拖影越明显；`=4` 退回 3.1.7 节奏。**显式设置它 = 同时关掉 2.8.0 的运动自适应**（它本来就是「锁死周期量数据」的开关） | 取消 / 按值 |

## 设置方法

- **当前会话（临时）**：`set BEAUTY_XXX=1`（cmd）或 `$env:BEAUTY_XXX="1"`（PowerShell）。
- **持久（用户级，双击 OBS 也生效）**：`setx BEAUTY_XXX 1`；撤销 `setx BEAUTY_XXX ""`。
- **只对某次启动**：用 `03_装机/6_launch_obs_test.bat` 等启动器注入，或 `verify_s1_correct.py --env K=V`。

## 回退原则（为什么这样设计）

1. 默认开的开关**只认 `0`**：拼错（如 `=ture`）不会误关，落在已验证的"开"侧。
2. 默认关的开关**只认 `1`**：拼错不会误开，落在旧的"关"侧。
3. 每个新开关都要**实际跑一次 `=0`（或 `=1`）验证回退**——开关本身也是被验收对象（见 PROGRESS §9.9 跨阶段门禁）。
