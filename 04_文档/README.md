## 四、阅读顺序建议

1. **新人第一天** → `../README.md` §1–§4
2. **要判断「能不能用/有什么坑」** → `../README.md` §2（正向）与 §3（负向）
3. **要干活了** → `开发流程与优化计划.md`（表 B 是作业指导书）
4. **要改某一段** → 对应的设计稿（输入旋转 → 方案B；掩码/帧环 → 方案A_5b2；五官 → 方案A_五官）
5. **要证明数字** → `../PROGRESS.md` 按 § 检索；测量口径见 `Phase0_基线测量规程.md`
