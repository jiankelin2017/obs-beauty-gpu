## 默认值约定（很重要）

- **默认开**：不设 = 开，**只认 `=0` 关闭**（拼错环境变量会落在"开"这一侧，即已验证的安全侧）。
- **默认关**：不设 = 关，**只认 `=1` 开启**（拼错落在"关"这一侧，回到旧行为）。
- 数值型：不设 = 自动，设了按值生效。

| `BEAUTY_MASK_DUMP` | 不设（不落盘） | **2.15.6**：把**生产用的** GPU 皮肤掩码 1:1 落盘（`<目录>/gpu_skin_<n>_<w>x<h>.raw`，8-bit，值 0..255）+ 同名 `.txt` 一行几何（`shape/count/cx/cy/a/b/rc/rs/lw/lh/fe/...`）。最多 5 张、`frame_tag % 90 == 0` 触发（≈3 秒一张）。用来分辨「看得见的边界」到底是矩形 / 椭圆 / 皮肤轮廓 —— 只看日志数字分不出来。配套 `03_装机/9_run_obs_maskdump.bat` 一键启动 | 取消环境变量即关闭（默认关，零成本） |
| `BEAUTY_FACE_PARSE` | 不设（关） | **2.16.2（研究开关，默认关）**：接入 BiSeNet(resnet18) 19 类人脸解析（`resnet18.onnx`，512×512，见 PROGRESS §9.52.6），把「非脸」像素从掩码里乘掉。**实测否掉了它作为默认能力**：① 手挡脸时去不掉手（掩码在手内占比 96.8%→85.7%，模型把手也判成 skin）；② 250~300 ms/次，进不了渲染路径。启用时会强制 CPU 掩码并停用缩略图路径 | 取消即关闭，逐字节回到默认行为 |
| `BEAUTY_HAND_MASK` | 不设（关） | **2.16.3**：手部检测（MediaPipe 手掌检测 ONNX，192×192，输出 [374,8]）。手框与脸相交时把手的区域从掩码里羽化扣掉（24 px），解决手挡脸时手上也有美白遮罩。**实测**：真实截图上手被检出（掩码 17.89%→16.50%），2.16.6 起：同一目录若有 `hand_landmark.onnx`，改用 **21 点关键点凸包**（按手腕→中指根旋正裁 224×224）抠出手形；实测掩码 17.89%→14.43%，边界跟手形走。启用时强制 CPU 掩码并停用缩略图路径 | 取消即关闭 |

## 设置方法

- **当前会话（临时）**：`set BEAUTY_XXX=1`（cmd）或 `$env:BEAUTY_XXX="1"`（PowerShell）。
- **持久（用户级，双击 OBS 也生效）**：`setx BEAUTY_XXX 1`；撤销 `setx BEAUTY_XXX ""`。
- **只对某次启动**：用 `03_装机/6_launch_obs_test.bat` 等启动器注入，或 `verify_s1_correct.py --env K=V`。

## 回退原则（为什么这样设计）

1. 默认开的开关**只认 `0`**：拼错（如 `=ture`）不会误关，落在已验证的"开"侧。
2. 默认关的开关**只认 `1`**：拼错不会误开，落在旧的"关"侧。
   **例外（2.14.0 起）**：`BEAUTY_GPU_REGION` 已翻默认开，改按第 1 条只认 `0`，不再适用本条。
3. 每个新开关都要**实际跑一次 `=0`（或 `=1`）验证回退**——开关本身也是被验收对象（见 PROGRESS §9.9 跨阶段门禁）。
